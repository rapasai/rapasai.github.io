# RapasAI Lab — Research 制作・更新・版管理規定

基準資料：サイトマップ_v3.docx（版管理・階層構造）、確定済みResearch HTML・共通CSS、および制作時に確定した規定。本書は制作・管理用であり、読者向けのHTMLには掲載しない。

## 1. サイト構造

設計用サイトマップには将来の構想を残し、公開用サイトマップには完成したページだけを掲載する。各入口には直下の項目だけを置き、下層の研究報告や記事を重複列挙しない。未完成の枝を工事中として公開しない。制作途中の無効リンクは公開前に接続するか、未完成の項目を非掲載にする。

## 2. 版管理規定（サイトマップ原本に準拠）

| 改訂区分 | 具体例 | 保存・公開方法 |
|---|---|---|
| 軽微な修正 | 誤字脱字、表記の統一 | 最新版を修正 |
| 情報更新 | 統計数値、事業進捗、資料の更新 | 改訂履歴と旧版を保存 |
| 部分改訂 | 一部の章・節、分析結果の変更 | 改訂履歴と旧版を保存 |
| 内容追加 | 新しい章・節、追加調査の反映 | 改訂履歴と旧版を保存 |
| 全面改訂 | 分析構造や政策提言の抜本的変更 | 改訂履歴と旧版を保存 |

初版は第1.0版。全面改訂は整数部分を更新し小数部分を0とする。情報更新・部分改訂・内容追加は小数部分を更新する。軽微な修正では最新版のみ修正し、版番号の更新や旧版保存を必要としない。

版管理はカテゴリーや章単位ではなく、個々の研究報告・政策提言全体を単位とする。改訂前の全文（全章および当該版に必要な図版等）を保存する。最新版の入口は維持する。初版公開時から改訂履歴を設け、旧版へのリンクは改訂が発生した段階で追加する。研究報告トップには版番号と公開日を明示する。公開日は実際の公開時に確定し、未確定の日付は記入しない。改訂履歴にも実際の公開日・改訂日と変更内容を記載する。

原本の例：第1.0版＝初版公開、第1.1版＝第8章の内容追加、第2.0版＝分析構造の全面改訂、第2.1版＝第4章の情報更新。旧版には第2.0版、第1.1版、第1.0版の全文を保存する。

## 3. HTML・デザイン制作規定

- 英語版の長文ページの建て付けを参考にした確定済みResearchページを鋳型とする。`research/assets/research.css` を共通使用し、書体・階層別文字サイズ・配色・表示幅・余白・カード・レスポンシブを管理する。Research専用ヘッダーを全Researchページで共通使用し、既存のロゴ、フッター、アクセス解析を維持する。
- 研究報告は総目次ページと章ごとの独立HTMLに分ける。総目次はタイトル、原本のタイトル画像、全章・全節の目次を掲載する。概要は新規作成しない。各章にはタイトル画像を表示しない。
- 各章は章タイトル、本文、PC右側の追従章内目次、章末参考文献、前章・総目次・次章へのリンクを持つ。狭い画面では目次を本文前に配置し、章内目次へ戻れる機能を維持する。
- 原稿の文章・数値・表・テキスト図・図版・出典を欠落させない。無断の加筆・削除・要約・画像加工を禁止する。表や図は原稿の対応箇所に配置し、表・テキスト図はコピー可能な形式を維持する。スマートフォンでは表が本文領域を破壊しないよう検証する。
- 指定された修正以外は変更しない。共通CSSの変更時には既存ページへの影響も検証する。

## 4. 表記・参考文献規定

章末参考文献の見出しは「参考文献」に統一する。原稿に「第9章の参考文献」など異なる見出しがある場合、HTML化の際に「参考文献」に修正する。総目次、章内目次、本文見出しのすべてに適用する。参考文献の内容・順序・URLや本文中の出典は変更しない。URLに追跡パラメータを追加しない。参考文献は原稿の各章末に維持する。

章番号は全ページの章タイトル、総目次、章内目次、章間リンク、メタデータで半角数字（第1章、第2章…）に統一する。原稿本文の一般的な数値表記には適用しない。

## 5. 閲覧・リンク規定

- Research内部リンクは `index.html` まで明示し、ローカル環境でもディレクトリ一覧を表示させない。節・参考文献への直接リンクは `index.html#アンカーID` を使用する。
- 参考文献、本文の外部出典、note等の外部リンクは `target="_blank" rel="noopener noreferrer"` で別タブに開く。Research内部の移動は同じタブとする。Research専用ヘッダーのロゴ・RapasAI LabはHP本体トップへ、ResearchはResearchトップへ、データセンター・デジタルインフラは研究領域トップへ接続する。宇宙探査・通信インフラは研究領域トップへ接続する。お問い合わせは既存HPのページを別タブで開く。Researchの英語版が未制作の間はEnglishボタンを表示しない。HP本体のヘッダーにはResearch入口を設け、Research専用ヘッダーとは区別する。
- 各下層ページ末尾に直接の上位階層へ明示的に戻るリンクを配置する。章ページには前章・総目次・次章への移動を設ける（存在する章のみ）。総目次の章・節・参考文献から該当箇所へ直接移動できるようにする。

- 両研究領域のArticlesは既存HPの記事の本棚（各研究領域トップから `../../index.html#books`）へ同じタブで直接接続する。専用記事一覧・記事画像・記事情報の複製は作成しない。記事更新は既存HPの本棚・蔵書ナビで行う。

## 6. 検索エンジン・OGP

各ページ固有のtitle、canonical、検索用メタ情報を設定する。検索用説明は原稿の見出し・研究対象など確認済み情報の範囲に限定し、独自の概要を付け加えない。報告書トップのタイトル画像はOGPに絶対HTTPS URLで指定し、各章のOGPには報告書の代表画像を共通使用する（章本文に画像を追加する意味ではない）。画像の実寸を指定する。noteの記事カード表示は公開後に実際に検証する。

### ページ種別ごとのメタデータ設定規定

- 全ページに固有の `title`、`meta description`、自己参照の `canonical`（公開先の絶対HTTPS URL）、`og:type`、`og:locale`（ja_JP）、`og:site_name`（RapasAI Lab）、`og:title`、`og:description`、`og:url`、`twitter:card`、`twitter:title`、`twitter:description` を設定する。OGPとTwitterのタイトル・説明は検索用タイトル・説明と一致させる。`og:url` はcanonicalと一致させる。
- 研究領域・カテゴリーの入口と改訂履歴は `og:type=website`。研究報告の総目次と各章は `og:type=article`。代表画像のある入口・研究報告では `og:image`、`og:image:width`、`og:image:height`、`og:image:type`、`twitter:image` を設定し、`twitter:card=summary_large_image` とする。代表画像のないページでは画像を新規作成せず、画像指定を省略し `twitter:card=summary` とする。
- 地域別調査の総目次の検索用タイトルは「地域名｜研究テーマ｜RapasAI Lab」、各章は「地域名｜第n章　正式な章タイトル｜研究テーマ｜RapasAI Lab」とする。例：北海道・石狩市｜GX戦略地域「データセンター集積型」｜RapasAI Lab。各章の検索用説明は正式な節タイトルを使用する。総目次の説明は地域名と研究テーマを含める。その他の研究報告でも報告書名と正式な章タイトルを用いる。改訂履歴の説明には報告書名と改訂履歴であることを明示する。
- メタデータのために画面上のタイトルや本文を変更しない。独自の概要、未確認の内容、画像を追加しない。OGP画像は原本を使用し、章ページには報告書の代表画像をメタデータとしてのみ指定する。
- canonical、og:url、XMLサイトマップのURLを一致させる。内部閲覧リンクは引き続き `index.html` を明示する。

XMLサイトマップは完成した公開対象URLに合わせて更新する。HP全体との統合および検索エンジンへの通知は本番公開時に行う。検索結果への掲載やOGP画像表示は設定だけで保証されない。

## 7. 提出前の検証

原稿とHTMLの全文・章節見出し・数値・表・図版・参考文献・URLを照合する。内部リンクの参照先とアンカー、外部リンクの別タブ設定、CSS・画像・アクセス解析の参照、PCとスマートフォンの実表示・操作、OGP・canonical・XMLサイトマップを確認する。既存ファイルとの変更差分およびZIPの破損を検証する。未検証項目は明示し、検証済みと扱わない。外部出典URLに接続できない場合は具体的URLを示して確認を依頼する。
