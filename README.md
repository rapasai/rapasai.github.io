# RapasAI Lab Web Site

GitHub Pages 用の静的サイト一式です。

## 更新内容

- `rapasai.jp` 用の `CNAME` を保持しています。
- `R-DR｜RapasAI Document Reviewer` の説明を、PDF画像ではなくHTML/CSSで再構成しています。
- サイト全体を緑ベースに寄せ、セクション背景の濃淡で区切りを明確にしています。
- 概要PDFは同梱していません。
- note記事4本へのリンクを「さらに詳しく読む」として掲載しています。
- `/ask/` 問い合わせページは維持しています。
- Formspree のフォーム送信URLは維持しています。
- 表示メールは `contact@rapasai.jp` です。

## 反映方法

Zipを展開し、展開後の中身をGitHubリポジトリ直下へ上書きしてください。Zipファイル自体はアップロードしません。

アップロード対象：

- `index.html`
- `style.css`
- `README.md`
- `CNAME`
- `rapasai-logo-mark.png`
- `ask/`

`assets/pdf/R-DR_overview.pdf` は削除対象です。
