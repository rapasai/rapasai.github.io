RapasAI Lab｜note記事の正式タイトル・表紙・公開日を参照する手順

【重要】
前回のZIPは、21記事のタイトルをnoteから実取得したものではありませんでした。
本版も、作成環境からnoteの実RSSに到達できないため、実同期の成功は未確認です。
GitHub Actionsで実RSSから記事21本すべてのタイトル・画像を取得できた場合にのみ公開します。

【修正内容】
・土台は rapasai_series_04_08_pdf_covers_update.zip。連載第0〜9回を保持。
・第6回のタイトルを、確認済みの正式な表記に訂正。
・全記事のnote RSSタイトルを取得できなければ同期を失敗させ、旧タイトルでの公開を防止。
・全記事の画像URLが確認できなければ同期を失敗させ、表紙消失を防止。
・取得成功時だけ articles.json を同期し、サイトをGitHub Pagesへ公開。
・日本語READMEをUTF-8で保持。ファイル名は変更しない。
・ZIPの中に covers フォルダは含めていない。初回成功前は旧リポジトリのcoversを削除しない。

【GitHubでの実実行】
1. GitHub Pagesの Source を GitHub Actions に変更。
2. ZIPを解凍してファイルをリポジトリへ上書きアップロード。
3. Actionsの「note正式タイトル・表紙同期とサイト公開」を Run workflow で実行。
4. 実RSS・画像・21記事照合・Pagesデプロイが全て成功したことを確認。
5. 公開サイトのタイトル、表紙、連載の本棚を確認。

【制限】
RSSに全21記事が存在しない場合は処理を中止します。RSSの公開件数に制限があるため、
記事数が増えた場合はnote各記事ページOGPなどによる不足分の取得を実装する必要があります。
本版はRSSデータを確認できていないので、現時点で全タイトルの完全一致は保証しません。
